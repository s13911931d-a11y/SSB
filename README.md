# SSB Messenger — نسخه آزمایشی ارتقایافته

پیام‌رسان فارسی مبتنی بر FastAPI و SQLite.

## امکانات
- ثبت‌نام و ورود با ایمیل به‌عنوان شناسه حساب (هر ایمیل یک حساب)
- رمزها با Argon2 هش می‌شوند
- گفت‌وگوی خصوصی، گروه و کانال
- فقط مدیر کانال یا ادمین برنامه می‌تواند در کانال پیام بفرستد
- عکس پروفایل، تصویر، پیام صوتی، ویدیو و فایل‌های رایج تا ۱۰ مگابایت
- انواع فایل‌های اداری Word/Excel/PowerPoint، PDF، PSD، ZIP و غیره به‌صورت دانلود
- API مدیریت ادمین برای فهرست‌کردن کاربران/گروه‌ها/کانال‌ها و تغییرنام/حذف گروه و کانال
- API حذف پیام توسط فرستنده، مالک اتاق یا ادمین

## راه‌اندازی ویندوز
از CMD داخل پوشه‌ای که `main.py` در آن است:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

برای اینکه حساب ادمین هنگام ثبت‌نام مشخص شود، پیش از ثبت‌نام اولیه در همان CMD مقدارها را تنظیم کن (ایمیل را با ایمیل خودت جایگزین کن و رمز را داخل کد پروژه ننویس):

```bat
set SSB_ADMIN_EMAIL=admin@example.com
set SECRET_KEY=یک_کلید_تصادفی_طولانی_و_خصوصی_حداقل_۳۲_نویسه
.venv\Scripts\python.exe -m uvicorn main:app --reload
```

سپس `http://127.0.0.1:8000` را باز کن و با همان ایمیل ثبت‌نام کن. برای حساب‌هایی که پیش از تنظیم `SSB_ADMIN_EMAIL` ساخته شده‌اند، این متغیر به‌تنهایی نقش ادمین را تغییر نمی‌دهد؛ برای استفاده واقعی باید ارتقای ادمین از مسیر امن دیتابیس انجام شود.

## محدودیت‌های مهم
- این نسخه ایمیل را به‌عنوان شناسه می‌پذیرد، اما هنوز کد تأیید ایمیل، بازیابی رمز و سرویس SMTP پیاده‌سازی نشده است. بنابراین اعتبار مالکیت ایمیل را تأیید نمی‌کند.
- پنل ادمین گرافیکی کامل در این نسخه وجود ندارد؛ عملیات مدیریتی از APIهای `/api/admin/overview` و `/api/admin/rooms/{id}/rename` و `/api/admin/rooms/{id}/delete` انجام می‌شود.
- بارگذاری محدود به ۱۰ مگابایت است. فایل‌های ناشناخته/اجرایی عمداً مسدودند. قبل از انتشار عمومی، اسکن بدافزار، محدودسازی نرخ درخواست، CSRF، کنترل دسترسی فایل‌ها و ذخیره‌سازی امن لازم است.
- اشتراک صفحه و بارگذاری فایل‌های بزرگ عمداً در این نسخه وجود ندارد.
- SQLite برای آزمایش محلی است؛ برای سرویس عمومی باید مهاجرت پایگاه داده، پشتیبان‌گیری، HTTPS و تنظیمات امن انجام شود.
